# Boss portraits

These thumbnails are derived from the in-game Boss UI artwork hosted by the
[MapleStory Wiki](https://maplestorywiki.net/). The underlying game artwork is
copyright NEXON Co., Ltd. Each image is resized to 96 pixels wide for use in the
boss tracker table.

The `gloom.png` and `darknell.png` files use the older Boss UI artwork available
for Giant Monster Gloom and Guard Captain Darknell; the remaining files use the
current Boss UI artwork.
